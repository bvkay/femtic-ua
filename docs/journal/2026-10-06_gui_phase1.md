## Built: src/femtic_gui (22 files, 3,393 lines, largest tabs/results.py 338; all LF, pyflakes and compileall clean)
- **Shell:** app.py (MainWindow: five tabs over the console in a splitter, Cancel, File > Open config Ctrl+O, Save
  as Ctrl+Shift+S, recent configs and run folders, Quit Ctrl+Q, Help > Runbook); `__main__.py` (optional config
  argument); theme.py (dark Fusion palette, all colours); console.py (console strip and a loguru sink).
- **config_io.py:** ruamel round-trip parse, line-targeted edits (only the value text on the key's line changes, the
  comment keeps its column; every edit is re-read by ruamel and PyYAML and anything else is refused). A no-op save
  writes the file's own bytes. validate() runs prep's load_config on a temp file next to the target. save_as() never
  overwrites, sets name and paths.run_dir from the new name, refuses a move of paths.root. UNC, WSL and //host
  paths are refused.
- **prep_api.py** is the only importer of scripts/prep_vulcan.py; every preview (sites, EDIs, rotation, bands, the
  floor readout as check C09 counts it, design warnings) is prep's own code. state.py holds the signals.
- **jobs.py:** JobRunner, one job at a time (no queue), `$ cmd` before and `--- label: done (exit 0)` / `failed
  (exit N)` / `failed to start` after, cancel with a 3 s wait, ANSI stripped, PYTHONUNBUFFERED=1. find_bash() returns
  C:/Program Files/Git/bin/bash.exe. Check and Run prep never pass --force.
- **Tabs:** Data (site table, map and band table selected together; curves with the EDI frame dashed and rotated
  solid; fmax_hz, fmin_hz, per_decade, require_all_sites and the four floors with a live readout; Check and Run prep
  disabled while unsaved). FEMTIC (the 16 control.dat keys, four editable, the rest say why not). Runs (INDEX.md
  table, RUN.md, the New-run form with one field per make_run.sh option, "Make run folder" through Git Bash, "Record
  result" rewrites only the job-id and verdict cells and shows the R6 git line; it runs no git). Mesh (counts,
  design warnings, read-only mesh keys, 3D buttons). Results (model, data fit with residual table, misfit map and
  observed-versus-calculated curves, convergence merged over archived femtic.cnv copies).
- **readers.py** (no Qt) and **viewer3d.py** (the only VTK importer, inside its functions; loads in a QThread; site
  area only, +-12 km and z -2 to 10 km; surface, three slices, log10 rho threshold, colour by rho or parameter cell,
  sites, east/north/up axes). tabs/common.py checks find_spec for vtk, vtkmodules, pyvista, pyvistaqt and
  femtic_mesh, and catches ImportError and OSError at Load.
- **Not built, by the reviewed design:** mesh design preview and Build button, an "Advanced" FEMTIC group, Save over
  the open file, a job queue.
- **Measured (PC, read-only on MAIN):** floor readout on config/vulcan_mesh_v2_rot.yml 2514/2443/2413/2511 of 2520
  (100/97/96/100 %) in 0.016 s, equal to prep's C09 line; bands 65 EDI, 53 candidates, 21 selected (per_decade 5:
